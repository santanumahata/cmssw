Bits added for newer filters (for example Photon 9, 10, 20; Electron 17, 19; Tau PNet entries; Jet 28 to 41) are empty for the earlier years in the same way. None of this is a code defect; it is the price of one bit list for five years of menus, and the documentation string does not say which years a bit covers.

The table is read off the scanner output for the master configuration against the frozen 2022 v1.2, 2022 v1.4, 2023, 2024, 2025 and 2026 menus and the development GRun menus. It is included to put the photon defect in context: the photon bits are the only ones that a menu cannot cure.
