Collection. setCollection stores the encoded tag of the collection the object came from: hltEgammaCandidatesUnseeded::HLT for the sub-leading leg, hltEgammaCandidates::HLT for the leading one.

Types and labels. addTriggerObjectType is called for every filter that referenced the object, so the unseeded object carries 92 and 81; addFilterLabel records every filter label, including the two unseeded last filters NanoAOD looks for.

patTrigger has onlyStandAlone = False and no excluded collections (the exludeCollections parameter is commented out in triggerLayer1/triggerProducer_cfi.py in 13_3_X and master), so nothing from the unseeded collection is lost at this stage.
