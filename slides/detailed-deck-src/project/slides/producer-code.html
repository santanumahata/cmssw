Abridged: bits stands for selected_bits[sel.id][&obj], skip for sel.skipObjectsNotPassingQualityBits.

Order of evaluation is the whole story. An object that fails sel never reaches qualityBits, never enters selected, and is never seen by the merging loop. No later step can restore it.

No break. Since 13_0_X an object is tested against every selection and can be written once per type it passes (an e/gamma object can be both id 11 and id 22). 12_4_X still had a break after the first match.

The version shown is upstream master, with two local aliases introduced for the slide width. Up to CMSSW_15_0_1 the bits were an int with assert(bit less than 31), the merging also required equal pT, and 12_4_X had a break after the first matching selection; the next slide tabulates the differences.
