Result. Every candidate of hltEgammaCandidatesUnseeded with Et > 22 GeV is saved with type 92 and the collection tag hltEgammaCandidatesUnseeded. On the seeded leg, HLTEgammaL1TMatchFilterRegional and HLTEgammaEtFilter save TriggerCluster as well.

Why it matters. The NanoAOD selection starts with type(92). It is satisfied for both legs, so the object type is not what rejects the unseeded objects; the next slide shows what the later filters save, and the slide after that where the types are merged.

TriggerTypeDefs.h: TriggerPhoton = 81, TriggerCluster = 92, TriggerL1EG = -98. HLT1Photon is HLTSinglet instantiated for reco::RecoEcalCandidate; the generic getObjectType returns 0 for that type, so the configured triggerType is stored.
