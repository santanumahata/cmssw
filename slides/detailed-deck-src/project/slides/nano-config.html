The NanoAOD Photon selection: one collection in sel, three unseeded filters in the bit list

# PhysicsTools/NanoAOD/python/triggerObjects_cff.py, master lines 88 to 116 (v13: 81 to 108), abbreviated

Photon = cms.PSet(
  id = cms.int32(22),
  sel = cms.string("type(92) && pt > 15 && coll('hltEgammaCandidates')"),
  l1seed = cms.string("type(-98)"),  l1deltaR = cms.double(0.3),
  skipObjectsNotPassingQualityBits = cms.bool(True),
  qualityBits = cms.VPSet(
    mksel("filter('hltEG33L1EG26HEFilter')","hltEG33L1EG26HEFilter"),                  # bit 0
    ...  # bits 1 to 13: HE filters, hltHtEcal800, EB tight-ID filters, Mu17_Photon30 photon leg
    mksel("filter('hltEG30LR9Id85b90eHE12R9Id50b80eR9IdLastFilter')", ...),              # 14
    mksel("filter('hltEG30LIso60CaloId15b35eHE12R9Id50b80eEcalIsoLastFilter')", ...),    # 15
    mksel("filter('hltEG22Iso60CaloId15b35eHE12R9Id50b80eTrackIsoUnseededLastFilter')", ...),  # 16
    mksel("filter('hltEG22R9Id85b90eHE12R9Id50b80eR9UnseededLastFilter')", ...),             # 17
    mksel("filter('hltEG30Iso60CaloId15b35eR9Id50b90eHE12b10eR9Id50b80eEcalIsoFilter')", ...),  # 18
    mksel("filter('hltEG18TrackIso60Iso60CaloId15b35eR9Id50b90eHE12b10eR9Id50b80e
           TrackIsoUnseededFilter')", ...),                                                # 19
    mksel("filter('hltEG*L1VBFLooseIsoEGHEFilter')", "hltEG*L1VBFLooseIsoEGHEFilter"),             # 20
  )
),

mksel turns a filter name into filter('name'), a list into an OR (max of the terms) and a tuple into an AND; bit i is the position in the VPSet unless bit= is given. No photon entry uses an explicit bit.

The contradiction is inside this one PSet: sel admits only hltEgammaCandidates, while bits 16, 17 and 19 name filters that run exclusively on hltEgammaCandidatesUnseeded (slide 7). No era modifier touches this block.

In NanoAOD v12 to v14 the list has 18 entries and the same four diphoton filters sit at bits 12, 13, 14, 15 (and 16, 17 for the 30_18 pair). The 21-entry list and the 64-bit filterBits branch arrived in CMSSW_15_0_2 with PR 47601, the backport of PR 47594.
