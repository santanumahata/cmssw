  R9UnseededLastFilter = cms.EDFilter(
  "HLTEgammaGenericFilter",

  candTag = cms.InputTag(
    "hltDiEG22HE12R9Id50b80eHEUnseededFilter" ),
  varTag = cms.InputTag(
    'hltEgammaR9IDUnseeded', 'r95x5' ),
  lessThan = cms.bool( False ),
  useEt = cms.bool( False ),
  thrRegularEB = cms.vdouble( 0.85 ),
  thrRegularEE = cms.vdouble( 0.9 ),
  ncandcut = cms.int32( 1 ),
  l1EGCand = cms.InputTag(
    "hltEgammaCandidatesUnseeded" ) )

  "HLTEgammaGenericQuadraticFilter",
  saveTags = cms.bool( True ),
  candTag = cms.InputTag( "hltEG22Iso60CaloId15b35e
    HE12R9Id50b80eEcalIsoUnseededFilter" ),
  varTag = cms.InputTag(
    "hltEgammaHollowTrackIsoUnseeded" ),
  lessThan = cms.bool( True ),
  useEt = cms.bool( True ),
  thrRegularEB = cms.vdouble( 6.0 ),
  thrRegularEE = cms.vdouble( 6.0 ),
  thrOverEEB = cms.vdouble( 0.002 ),
  thrOverEEE = cms.vdouble( 0.002 ),
  ncandcut = cms.int32( 1 ),
  l1EGCand = cms.InputTag(
    "hltEgammaCandidatesUnseeded" ) )

candTag points to the previous filter of the chain (the objects to test), varTag to the variable producer, and l1EGCand to the candidate collection the filter tags its saved objects with. The seeded last filters are identical in structure with l1EGCand = hltEgammaCandidates. Module names are broken over two lines here only for display.

HLTEgammaGenericFilter and HLTEgammaGenericQuadraticFilter are the standard e/gamma selection modules; the quadratic variant applies a threshold that grows with Et (thrOverE terms). Both read l1EGCand and use it as the collection tag of the objects they save, as the next slides show in the plugin code.
