MiniAOD slims the objects but keeps the collection name; NanoAOD unpacks the labels again

# PatAlgos/python/slimming/selectedPatTrigger_cfi.py

selectedPatTrigger = cms.EDFilter(
  "PATTriggerObjectStandAloneSelector",
  src = cms.InputTag("patTrigger"),
  cut = cms.string("!filterLabels.empty()")
)

Keeps every object accepted by at least one filter with saveTags. The unseeded photons carry their last-filter labels, so they stay.

# PatAlgos/python/slimming/slimmedPatTrigger_cfi.py

slimmedPatTrigger = cms.EDProducer(
  "PATTriggerObjectStandAloneSlimmer",
  src = cms.InputTag("selectedPatTrigger"),
  triggerResults =
    cms.InputTag( 'TriggerResults::HLT' ),
  packFilterLabels = cms.bool(True),
  packP4 = cms.bool(True),
)

Packs the four-vector and the filter labels; the collection string and the type list are stored as they are.

# NanoAOD/python/triggerObjects_cff.py, lines 8 to 12

unpackedPatTrigger = cms.EDProducer(
  "PATTriggerObjectStandAloneUnpacker",
  patTriggerObjectsStandAlone =
    cms.InputTag('slimmedPatTrigger'),
  triggerResults =
    cms.InputTag('TriggerResults::HLT'),
  unpackFilterLabels = cms.bool(True)
)

Restores the labels so that filter('...') can be evaluated; hasFilterOrCondition throws if labels are still packed.

Proof that the unseeded objects really reach NanoAOD: the Electron selection has accepted coll('hltEgammaCandidatesUnseeded') since June 2023 and its bit "2e (CaloIdL_MW unseeded)" is populated in production files. The same objects enter the Photon branch of the producer and are rejected there.

From MiniAOD onward the object is a pat::TriggerObjectStandAlone with: the packed four-vector, the collection string, the list of trigger object types, the packed filter labels and the path names. NanoAOD reads it back through unpackedPatTrigger and hands it to TriggerObjectTableProducer.
