Why this form

Names exactly the two collections and copies the Electron selection of PR 41827. A wildcard would also match (next slide) but would admit any future collection with that prefix.

What changes

Unseeded objects enter the photon branch; with the skip flag only those that set a photon bit are written, and the only photon-bit filters on the unseeded collection are the three diphoton ones. A seeded twin in the same direction is merged with OR-ed bits.

What does not

Bit numbers, documentation strings, the other object types and the event content. Only events that fired a diphoton trigger gain photon rows.
