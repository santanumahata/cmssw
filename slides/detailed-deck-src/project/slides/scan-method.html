def glob_re(pat):  # NanoAOD wildcard semantics
  parts = pat.split("*")
  return re.compile("^" + ".*".join(
      re.escape(p) for p in parts) + "$")

def collections_of(mods, name):
  # EDProducer labels a filter saves its objects from
  typ, body = mods[name]
  for p in ("l1EGCand", "inputTag", "CandTag",
            "inputCandCollection", "originTag1", ...):
    for lab in tag_labels(body, p):
      if mods[lab][0] == "EDProducer": direct.add(lab)
      elif mods[lab][0] == "EDFilter": follow.append(lab)
  return direct or union(collections_of(mods, f) for f in follow)

status = OK if any matched filter's collection passes coll()
        else COLL if filters match but none passes
        else STALE if no module matches the pattern

Inputs

Configs: master, 15_0_X (v15), 13_3_1_patch1 (v13), 13_0_13 (v12). Menus: frozen 2022 v1.2 and v1.4, 2023 v1.2, 2024 v1.4, 2025 v1.3, 2026 v1.3, plus the GRun development menus of 13_0_X, 14_0_X, 15_0_X and 16_1_X.

What it emulates

mksel (lists are ORs, tuples ANDs), the anchored star matching of hasAnyName, the collection each matched filter saves (following inputTag chains for combination filters), and the coll() terms of each selection. The type test is not emulated; the Tau selection's coll('*Tau*') is OR-ed with filters and treated as non-restrictive.

Outputs

Per config, selection, bit and menu: OK, COLL, STALE or UNK (L1-seed modules, accepted by type). Raw outputs are in scan/ of the notes repository.

The scanner reads the menu files as text (module definitions parsed with a small bracket matcher), so it works without a CMSSW installation. It reproduces the photon finding and extends the check to the Electron, Muon, Tau, BoostedTau, Jet, FatJet, MET, HT and MHT selections.
